# 幻境倍率公式化扩展 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让幻境等级可开放到 1 亿/100 亿倍,数据库只存"基础模板 + 每级增量系数",运行时按公式即时算出任意等级数值,彻底告别物化海量数据行。

**Architecture:** 三条主线并行——(1) 倍率字段全链路 int256 化,消除 uint32/float 溢出与精度损失;(2) 鉴定模板从 10 万物化行改为 N 行"稀有度档位"+每级增量字段,运行时按幻境等级套公式算词缀百分比;(3) 幻境生物属性加"通用模板行"(等级=0)+每级增量,实现原作者已声明未写的 `GenerateDefaultCreatureConfig`,任意等级从通用行算倍率。C++ 代码不出现任何具体数字,行数/系数/公式类型全是数据库字段值。

**Tech Stack:** C++17 (AzerothCore 模块), MySQL (utf8mb4), boost::multiprecision (int256/uint256), CMake 构建。

## Global Constraints

- **不硬编码任何数字**:C++ 中不得出现 20(行数)、300(模式阈值)、1.20(斜率)等魔法数字。行数、系数、公式类型、模式全部读数据库字段。
- **属性值本身不改类型**:血量/伤害/装备属性已是 uint256/decimal(65,0),不动。只改"倍率"这个数字的存储/传递/计算类型。
- **列名/表名用简体中文**(遵循本 fork 既有约定,如 `_幻境生物属性`、`待鉴定物品标记`)。
- **饱和转换**:所有大数计算用 `Acore::Number::ToInt256Saturated`/`ToUInt256Saturated`/`SaturatingMultiplyUInt256`,禁止裸算术溢出。
- **无单元测试框架**:验证 = 编译通过 + SQL 导入行数核对 + 服务器启动日志无错 + GM 命令游戏内实测。
- **向后兼容**:新增字段一律 `ADD COLUMN ... DEFAULT <安全默认>`,旧数据/旧行为在不配置新字段时保持不变。
- **公式类型首版只实现线性**(`基础 + 幻境等级 × 每级增量`),字段预留指数(值=1)但不实现其数学。

```cpp
HuanJingCreatureConfig HuanJingSystem::GenerateDefaultCreatureConfig(uint32 huanJingLevel)
{
    // 从"等级=0 通用模板行"按线性公式生成该等级配置:倍率 = 基础倍率 + 等级 × 每级增量
    HuanJingCreatureConfig config{};
    config.configId = 0;
    config.huanJingLevel = (int32)huanJingLevel;
    config.creatureId = -1;
    config.creatureType = -1;
    config.mapId = -1;
    config.areaId = -1;
    config.minLevel = -1;
    config.maxLevel = -1;

    // 查通用模板行(等级=0),取其基础倍率与每级增量作锚点
    HuanJingCreatureConfig const* base = FindTemplateAnchorConfig();  // 见 Step 3
    double lvl = static_cast<double>(huanJingLevel);
    auto linear = [lvl](double baseMul, double inc) -> float {
        double v = baseMul + lvl * inc;
        return v < 0.0 ? 0.0f : static_cast<float>(v);
    };
    if (base)
    {
        config.healthMultiplier      = linear(base->healthMultiplier, base->healthPerLevelInc);
        config.minDamageMultiplier   = linear(base->minDamageMultiplier, base->damagePerLevelInc);
        config.maxDamageMultiplier   = linear(base->maxDamageMultiplier, base->damagePerLevelInc);
        config.armorMultiplier       = linear(base->armorMultiplier, base->armorPerLevelInc);
        config.attackPowerMultiplier = linear(base->attackPowerMultiplier, base->attackPowerPerLevelInc);
        config.spellPowerMultiplier  = linear(base->spellPowerMultiplier, base->spellPowerPerLevelInc);
        config.manaMultiplier        = base->manaMultiplier;
        config.equipAttrMultiplier   = base->equipAttrMultiplier;
        config.equipAttrValue        = base->equipAttrValue;
        config.equipAttrMode         = base->equipAttrMode;
        config.identificationGroup   = base->identificationGroup;
        config.identificationQuality = base->identificationQuality;
        config.formulaType           = base->formulaType;
    }
    else
    {
        // 无通用模板行时的兜底:全 1 倍(保持原版,不放大)
        config.healthMultiplier = config.minDamageMultiplier = config.maxDamageMultiplier =
        config.armorMultiplier = config.attackPowerMultiplier = config.spellPowerMultiplier =
        config.manaMultiplier = 1.0f;
        config.equipAttrMultiplier = 1.0f;
    }
    return config;
}
```

```cpp
bool HuanJingSystem::EnsureCreatureConfigExists(uint32 huanJingLevel)
{
    if (huanJingLevel == 0) return true;
    if (huanJingLevel > _maxLevel) return false;

    std::unique_lock<std::shared_mutex> lock(_creatureConfigsMutex);
    for (auto const& c : _creatureConfigs)
        if (c.huanJingLevel == (int32)huanJingLevel)
            return true;
    _creatureConfigs.push_back(GenerateDefaultCreatureConfig(huanJingLevel));
    // 生成新行后清匹配缓存,避免旧"未命中(nullptr)"结果残留
    {
        std::lock_guard<std::mutex> cacheLock(_configMatchCacheMutex);
        _configMatchCache.clear();
    }
    return true;
}
```
