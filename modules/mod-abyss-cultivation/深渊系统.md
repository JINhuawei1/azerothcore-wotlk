# 修仙深渊：万劫轮回 开发文档

## 1. 当前模块定位

- 模块名称：`mod-abyss-cultivation`
- 当前定位：`章节推进 + 遗物收藏/激活 + 装备图鉴 + 奖励历史 + 深渊流程骨架`
- 当前状态：`已移除图鉴、局内构筑、局内效果模板、事件模板、品质配置相关的对外功能`

## 2. 当前保留的功能

### 2.1 专属装备页

已完成：

- 遗物列表展示
- 收藏状态展示
- 装配状态展示
- 主/副/阶段/终极槽位切换
- 清空槽位
- 槽位与冲突校验

### 2.2 装备图鉴页

已完成：

- 展示普通底材与传奇唯一

- 仅看已持有
- 已持有标记
- 点击图标跳转对应章节
- 清除筛选
- 当前筛选状态显示

### 2.3 剧情章节页

已完成：

- 章节列表

- 查看本章装备

### 2.4 奖励历史页

已完成：

- 历史奖励展示
