## 设计理念

打造一个深邃、神秘且精致的修仙主题UI。以暗紫色为基调、金色为点缀，营造"古老修仙法器"般的沉浸感。在WotLK 3.3.5 API限制内最大化视觉品质。

---

## 涉及文件

- `AbyssCultivationUI.lua` - 主要改动文件（全部UI代码）
- `AbyssCultivationUI.xml` - 主框架定义（微调尺寸）

## Phase 1: 主题色板与基础工具函数重构

### 1.1 更新 `THEME` 色板（第95~113行区域）

**新色板方向：**
- 背景层次更丰富：深渊黑 → 暗紫 → 面板紫，三级递进
- 金色系：主金、亮金、暗金，用于标题/高亮/边框
- 紫色系：主紫、亮紫、暗紫，用于装饰/光效/选中态
- 卡片增加 `cardHover` 悬停态颜色
- 增加 `divider`（分割线）、`headerBg`（标题栏底色）专用色

### 1.2 重写 `StylePanel()` 函数（第208~217行）

- 主框架改用 `Interface\DialogFrame\UI-DialogBox-Border`（edgeSize=24），视觉更厚实精致
- 内部面板保持 `UI-Tooltip-Border` 但调整 edgeSize=14 和 insets
- 新增 `StylePanelPremium(frame)` 函数：专用于主框架，使用金色边框
- 新增 `StylePanelCard(frame)` 函数：卡片专用，更细的边框 + 自定义底色
- 新增 `StylePanelFlat(frame)` 函数：无边框纯底色面板

### 1.3 新增装饰工具函数

```lua
-- 创建水平分割线（金色渐变效果）
CreateDivider(parent, yOffset)

-- 创建角落装饰（四角金色光点）
CreateCornerGlow(parent)

-- 创建标题文字（带微光效果 - 底层暗色阴影+上层亮色文字）
CreateGlowTitle(parent, text, size)

-- 创建图标框架（带品质色边框光晕）
CreateStyledIconFrame(parent, size)
```

### 4.2 卡片构建函数重写（`GetOrCreateRelicCard` 等多个函数）

**涉及函数：**
- `GetOrCreateRelicCard`（第1821行）
- `GetOrCreateArtifactCard`（第2149行）

- `GetOrCreateSetOverviewCard`（第2738行）

**卡片视觉改进：**

   - 图标尺寸增大到40x40
   - 图标边框使用独立的小面板框架，边框色随遗物类型/品质变化
   - 在图标边框外层添加微弱光晕纹理（`CheckButtonGlow`，低透明度）
   - 已装配的图标外层光晕更亮（绿色）

2. **文字布局**：
   - 名称字体保持 `GameFontHighlight`，但增加左边距

4. **悬停效果**（新增 OnEnter/OnLeave 给卡片本体）：

   - 离开时：恢复原状
   - 使卡片本身可交互（EnableMouse），不影响子元素点击

5. **已装配状态**：
   - 左侧状态条绿色 + 微弱绿色光晕
   - 卡片边框变为暗绿色
   - 背景色带微弱绿色调

6. **未收藏状态**：
   - 图标添加半透明灰色遮罩层
   - 整体透明度降低
   - 名称使用暗灰色
