# 图鉴系统

## 简介

图鉴系统是一个为AzerothCore开发的模块，提供了一个可配置的图鉴收集系统。玩家可以收集特定物品来激活图鉴，并通过集齐特定组合的图鉴来触发羁绊效果，获得额外奖励。

## 功能特点

- **多级菜单结构**：支持一级和二级菜单分类
- **图鉴等级系统**：图鉴可以有多个等级，随着收集的进度提升
- **自定义图片**：支持为每个图鉴设置自定义图片，包括序列帧动画
- **图片位置调整**：可以调整图片的X和Y轴偏移
- **激活奖励**：激活图鉴后可以执行自定义GM命令
- **羁绊系统**：集齐同一组的图鉴可以触发羁绊效果，获得额外奖励

## 安装说明

1. 将模块复制到AzerothCore的`modules`目录
2. 重新运行CMake并编译服务器
3. 导入SQL文件到数据库
4. 在`worldserver.conf`中启用模块

## 数据库结构

### _图鉴系统表

该表存储图鉴的基本信息：

| 字段名 | 类型 | 描述 |
|--------|------|------|
| 注释 | varchar(2000) | 图鉴的描述或注释 |
| id | int | 图鉴ID，同一个栏位，id一样，按等级升级 |
| 一级菜单名称 | varchar(2000) | 图鉴所属的一级菜单名称 |
| 一级菜单图标 | varchar(2000) | 一级菜单的图标 |
| 二级菜单名称1 | varchar(2000) | 图鉴所属的二级菜单名称1 |
| 二级菜单名称2 | varchar(2000) | 图鉴所属的二级菜单名称2 |
| 二级菜单图标 | varchar(2000) | 二级菜单的图标 |
| 第几页 | int | 图鉴显示在第几页，每页不超过28个 |
| 等级 | int | 图鉴当前等级 |
| 最大等级 | int | 图鉴最大等级 |
| 物品entry | int | 激活图鉴所需的物品ID，必须唯一 |
| 图片名 | varchar(255) | 图鉴的图片名称 |
| 图片数量 | int | 序列图片的数量，系统会循环播放 |
| 图片偏移x | int | 图片X轴偏移像素 |
| 图片偏移y | int | 图片Y轴偏移像素 |
| 激活需求 | int | 激活图鉴的需求 |
| 激活后执行GM命令 | varchar(2000) | 激活图鉴后执行的GM命令 |
| 羁绊组 | int | 图鉴所属的羁绊组，同组图鉴集齐可触发羁绊效果 |

### _图鉴系统_套装表

该表存储图鉴套装（羁绊）的信息：

| 字段名 | 类型 | 描述 |
|--------|------|------|
| 注释 | varchar(2000) | 套装的描述或注释 |
| 组 | int | 套装组ID |
| 激活描述 | varchar(2000) | 激活套装后显示的描述 |
| 激活模版_物品技能_多个逗号隔开 | varchar(2000) | 激活套装后获得的技能模板，多个用逗号分隔 |
| 激活后执行GM命令 | varchar(2000) | 激活套装后执行的GM命令 |

## 配置选项

在`mod_tujian_system.conf.dist`中可以配置以下选项：

```
# 启用图鉴系统
TujianSystem.Enable = 1

# 在服务器启动时显示加载信息
TujianSystem.Announce = 1
```

## 使用示例

### 添加图鉴

```sql
INSERT INTO `_图鉴系统` 
(`注释`, `id`, `一级菜单名称`, `一级菜单图标`, `二级菜单名称1`, `二级菜单名称2`, `二级菜单图标`, 
`第几页`, `等级`, `最大等级`, `物品entry`, `图片名`, `图片数量`, `图片偏移x`, `图片偏移y`, 
`激活需求`, `激活后执行GM命令`, `羁绊组`) 
VALUES 
('传说武器', 1, '武器图鉴', 'weapon_icon', '传说武器', '稀有收藏', 'legendary_icon', 
1, 1, 3, 12345, 'legendary_sword', 3, 0, 0, 
0, '.add spell 12345', 1);
```

### 添加套装

```sql
INSERT INTO `_图鉴系统_套装` 
(`注释`, `组`, `激活描述`, `激活模版_物品技能_多个逗号隔开`, `激活后执行GM命令`) 
VALUES 
('传说武器套装', 1, '集齐所有传说武器，获得额外10%攻击力', '12345,12346,12347', '.add spell 23456');
```

## 客户端支持

本模块需要配合客户端插件使用，客户端插件负责显示图鉴界面和处理玩家交互。

## 开发者信息

如需添加更多功能或修改现有功能，可以编辑`mod_tujian_system.cpp`文件。主要的数据结构和函数如下：

- `TuJianEntry`：图鉴条目结构
- `TuJianSetEntry`：套装条目结构
- `LoadTuJianData()`：加载图鉴数据
- `LoadTuJianSetData()`：加载套装数据
- `TujianSystemWorldScript`：处理配置加载和数据初始化

## 常见问题

1. **图鉴不显示？**
   - 检查数据库表是否正确创建
   - 确认已添加图鉴数据
   - 验证客户端插件是否正确安装

2. **激活命令不执行？**
   - 检查GM命令格式是否正确
   - 确认玩家权限是否足够

3. **羁绊效果不触发？**
   - 确认所有同组图鉴都已激活
   - 检查套装表中的组ID是否与图鉴表中的羁绊组匹配
