# 技能综合大师模块

集成所有职业可学习技能的综合NPC，每个职业看到自己对应的技能大师。

## 功能特点

- **职业技能学习**: 战士看到战士技能，法师看到法师技能，每个职业显示对应的技能列表
- **武器技能学习**: 所有武器类型技能（剑、斧、锤、匕首、法杖等）
- **骑术学习**: 从学徒骑术到大师骑术，包括飞行骑术

## 安装步骤

1. 将模块文件夹放入 `modules` 目录
2. 重新编译服务器
3. 执行SQL文件:
   - `01_skill_master_npc.sql` - 创建NPC
   - `02_skill_master_data.sql` - 创建数据表
   - `03_import_from_npc_trainer.sql` - 从现有训练师导入数据
4. 复制 `conf/SkillMaster.conf.dist` 到服务器配置目录并重命名为 `SkillMaster.conf`
5. 在游戏中使用 `.npc add 600100` 添加NPC

## 配置选项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| SkillMaster.Enable | 1 | 是否启用模块 |
| SkillMaster.NpcEntry | 600100 | NPC Entry ID |

## 数据表说明

### `_技能大师` 表结构

| 字段 | 类型 | 说明 |
|------|------|------|
| type | INT | 类型: 1-11为职业ID, 100=武器技能, 101=骑术 |
| spell_id | INT | 技能ID |
| spell_cost | INT | 学习费用(铜币) |
| req_skill | INT | 需求技能ID |
| req_skill_value | INT | 需求技能等级 |
| req_level | TINYINT | 需求等级 |
| req_spell | INT | 需求前置技能 |
