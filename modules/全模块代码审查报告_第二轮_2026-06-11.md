### 1. 构建系统陷阱：AC_ADD_SCRIPT 是无效宏（高危）

### 3. 线程安全：无锁全局容器 ×40+ 处（MapUpdate.Threads>1 即随机崩溃）

几乎每个模块都有"全局/静态 unordered_map + PlayerScript/UnitScript 地图线程钩子读写"组合，本轮新确认的重灾区：abyss(17 个 map+脚本成员)、huanjin(多处旁路锁)、item-growth、custom-ai、vip(_playerVipData 钩子内插入)、xianmen(_regenTimers 等)、rune、breakthrough(登录事件地图线程写)、enhancement、item-skills(共享 mt19937 shuffle)、wuhun(_players)、ascension/item-sets/hardcore、creature-attributes、item-recycle、item-commerce(_charLeaseItems vector)、cultivation、popup、quest-reward、cut(_pendingHitNotifications)、heal-rune(_playerTickTimers)、backpack-bonus(5 个 map)、reincarnation、fashion、material-warehouse、map-attributes、model-control、challenge-mirage、chenghao、announcement(重载 clear)、class-attributes(_playerModifiers)、talent-soul(锁外指针)、player-attribute-panel、auto-group、map-creature-adjust/pet-property(共享 mt19937)。

**整改决策（二选一，写进部署基线）**：
- 把 `MapUpdate.Threads = 1` 定为部署红线（当前 worldserver.conf 即为 1，风险休眠），并在文档声明所有模块按单线程地图假设编写；或
- 统一方案逐模块加 `std::shared_mutex` / 数据下沉 Player/Creature 对象（工作量大，建议仅对计划开多线程地图时执行）。

### 4. Addon/聊天消息无节流（客户端可刷 = 主线程 DoS 面）

几乎所有带 UI 的模块的 `OnPlayerChat`/Addon 入口无频率限制，且多数每条消息触发同步查库或大量发包：abyss(REQ_ALL 全表扫描+数十 chunk)、huanjin(HUANJING_QUERY)、xianmen(REQ_ALL 7-8 次查库)、identification(IDENTIFY_BATCH)、magic-hit(BOSS_MAP_REQUEST 大 UNION)、wuhun(REQ_EQUIP 重建装备)、rune(按任意 guid 查库无所有权校验)、breakthrough(直通 ParseCommands 执行任意聊天命令)、boundary(UPGRADE ≈9 次同步往返)、talent-soul(RESET_TALENT 同步 DirectExecute)、cut/heal-rune(REQ_* 同步查库)、tujian(COLLECT O(N²)+批量写)、mirage(ENTER 两条写+全量重刷)、material-warehouse(REQ 每页 200 个独立包)、popup、plugin-manager(SAVE_POS 无限灌写)、hardcore、item-recycle、chenghao、promotion(REQ_INFO 千次扫描)、player-attribute-panel、mall、cultivation。

**整改**：统一基建——每玩家每前缀 1-2 秒令牌桶节流 + "内存即权威，REQ_* 一律读缓存" + 任意 guid 参数必须做所有权校验。

### 5. 写后回读 / 异步写+同步读竞态（数据一致性模式错误）

wuhun 装备、rune 镶嵌、item-attributes(Clear 异步 vs Save 同步)、redemption(检查与扣减分离)、boundary(SpendBoundaryTotalExp 验证读)、breakthrough(扣点)。**整改范式**：写路径用同步条件 UPDATE（看受影响行数）或同一事务；写成功后信任内存态，删除"写后立即重读"。

### 6. 其他批量项

- **printf 占位符喂 fmt**：item-skills(`%.1f`)、item-with-ai(`%10u`) 等，输出原样格式串。
- **strtok((char*)args)** 原地改写 const 缓冲区 UB：identification、mall、announcement、item-commerce。
- **每次调用新建 random_device+mt19937**：reward-template、location、item-synthesis、magic-hit、redemption、item-with-ai(伤害热路径!)。统一改核心 `urand/roll_chance_f` 或 thread_local。
- **`std::rand()`**：abyss(RAND_MAX=32767 导致高权重候选抽不中)、event-trigger。
- **重载命令运行时 clear 配置容器** → 地图线程持有指针悬垂：creature-attributes、enhancement、item-attributes、reward-template、talent-soul、wuhun、map-attributes、announcement、model-control、item-with-ai。统一改 shared_ptr 快照原子交换。
- **高频 LOG_INFO 未降级**：xianmen、mall、breakthrough、material-warehouse、announcement、item-attributes(基础属性替换追踪)、rune。
