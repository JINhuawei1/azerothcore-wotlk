# 物品回收系统

## 功能概述

物品回收系统允许玩家自动或手动回收背包中的物品，并根据配置获得相应的奖励。

## 回收奖励逻辑

系统采用三级奖励机制：

1. **奖励模板优先**：如果物品配置了奖励模板ID（>0），则使用奖励模板发放奖励
2. **商店价格奖励**：如果奖励模板ID为0，则检查物品的商店出售价格
   - 如果物品有商店出售价格（SellPrice > 0），按商店价格给予货币奖励（铜币为基础单位）
   - 如果物品没有商店出售价格（SellPrice = 0），则摧毁物品，无奖励

## 配置说明

### 数据库表：物品_回收

- `回收奖励`：奖励模板ID
  - 0：按商店价格给货币奖励或摧毁
  - >0：使用指定的奖励模板

### 货币系统说明

- 货币以铜币为基础单位存储和计算
- 显示格式：1金 = 100银 = 10000铜
- 回收消息会自动转换为合适的金银铜格式显示

### 玩家命令

- `.回收 界面` - 打开回收界面
- `.回收 自动 [开启/关闭]` - 切换自动回收
- `.回收 回收 [组ID]` - 手动回收指定组
- `.回收 状态` - 查看回收状态
- `.回收 设置` - 配置回收参数

## 使用示例

1. 配置灰色垃圾物品按商店价格回收：
   ```sql
   INSERT INTO `物品_回收` (`id`, `回收奖励`, `回收类型`, `品质要求`)
   VALUES (1, 0, 4, 0);
   ```

2. 配置蓝色装备使用奖励模板：
   ```sql
   INSERT INTO `物品_回收` (`id`, `回收奖励`, `回收类型`, `品质要求`)
   VALUES (2, 1001, 1, 3);
   ```

## 注意事项

- 炉石等重要物品默认被过滤，不会被回收
- 已装备的物品可以选择保护，避免误回收
- 支持按物品类型、品质、等级等条件过滤
- 自动回收间隔可配置（10-3600秒）
